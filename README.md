# برندکیت گزارش کارفرمای آتی فرزام — نسخهٔ ۳٫۰

سیستم رسمی ساخت گزارش‌های کارفرما برای **آتی فرزام** (توسعهٔ نرم‌افزار و سخت‌افزار ردیاب هوشمند): گزارش HTML فارسیِ راست‌به‌چپ روی صفحهٔ استاندارد **A4** که با چاپ مرورگر به PDF تمیز و حرفه‌ای می‌رسد.

**ایدهٔ مرکزی:** هیچ گوشهٔ تیزی و هیچ مشکی‌ای در کار نیست؛ تیره‌ترین رنگ `#102333` است و کنارش رنگ‌های زندهٔ کنترل‌شده می‌نشینند. از فایل پترن هم تصویر استفاده نمی‌شود؛ ساختارش استفاده می‌شود: **جدول اقداماتِ کاشی‌دار** و **نمودارهای مسیر، قوس و ماتریس نقطه‌ای**. قفل برند دوزبانه است: تایپوگرافی فارسی + `svg/typography english.svg`.

## از کجا شروع کنم؟

| نیاز | فایل |
|---|---|
| دیدن و فهمیدن خودِ برندکیت | [`index.html`](index.html) — سند زنده: زبان فرمی، رنگ، تایپوگرافی، مدل‌های نمودار، اسکلت صفحه |
| دیدن یک گزارش کامل و چاپش | [`demo-report.html`](demo-report.html) — دموی ۵ صفحه‌ای در مقیاس واقعی A4 |
| ساختن گزارش جدید | [`brand-kit/templates/report-template.html`](brand-kit/templates/report-template.html) |
| سپردن کار به AI Agent | [`SKILL.md`](SKILL.md) — یا پرامپت آماده در بخش ۰۶ `index.html` |

اجرا: `python3 -m http.server 8000` و باز کردن `http://localhost:8000` — بدون هیچ وابستگی خارجی.

## خروجی PDF

چاپ مرورگر: مقصد **Save as PDF** · کاغذ **A4** · حاشیه **None** · مقیاس **۱۰۰٪** · **Background graphics فعال**. هر `.a4-page` دقیقاً یک برگ PDF است.

## قواعد در یک نگاه

- **فرم:** هیچ گوشهٔ تیزی (شعاع ≥۱۰px؛ امضای ربع `28/14`) و تصویر پترن در خروجی ممنوع؛ ساختارش در جدول و نمودار می‌آید.
- **رنگ:** تیره‌ترین `#102333` ـ مشکی ممنوع؛ آبی سیگنال و سبزآبیِ زنده برای داده، کهربایی برای هدف/هشدار، مرجانی برای خطا.
- **داده:** چهار مدل نمودار پترنی ـ نوار مسیر، خط مسیر، قوس سهم، ماتریس نقطه‌ای ـ با عنوان پیام‌دار، شمارهٔ شکل و منبع.
- **جدول اقدامات:** `.af-ptable` با هدر کاشی توپر، ربع چرخان در ستون اول و پیشرفت پنج‌نقطه‌ای.
- **صفحه:** چیدمان میلی‌متری با بلوک پایانی چسبیده به کف (`.af-push`)؛ قفل دوزبانه در جلد/هدر/فوتر؛ پایان با امضای سه‌طرفه.
- **متن:** فقط پیدا؛ اعداد فارسی؛ عبارت فنی لاتین داخل `span.af-ltr`.
